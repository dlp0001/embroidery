# Архив страниц

Снимки страниц сайта в том виде, в каком они были на проде. Лежат вне
`public`, поэтому сайт их не раздаёт. Открываются из папки двойным щелчком
по `index.html`: картинки лежат рядом, шрифты тянутся из Google Fonts.
